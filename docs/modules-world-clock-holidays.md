## 一、时区汇率（Time Zone & Currency）

**文件**：`src/features/clock/app/ClockPage.tsx`

### 功能概览

`/clock` 已统一为“时区汇率”工具，包含“时间”和“汇率”两个页内 Tab。时间 Tab 展示全球多城市当地时间，支持拖动时间轴联动各城市；汇率 Tab 提供外币兑人民币的快速换算、关注货币和走势查看。

### 核心功能

#### 1. 时间 / 汇率 Tab
- 页头标题、面包屑、左侧菜单和权限模块名称统一为 **时区汇率**
- 默认进入“时间”Tab
- “时间”Tab 副标题：拖动时间轴，各城市同步联动
- “汇率”Tab 副标题：实时汇率，快速换算

#### 2. 默认城市与本地城市
- 默认本地城市为 **上海**（`HOME_CITY_ID = 'shanghai'`），可在页面中切换本地城市
- 默认显示 8 座城市：上海、纽约、洛杉矶、伦敦、柏林、悉尼、迪拜、新德里
- 可在 32 座全球城市中自由添加 / 删除（当前本地城市不可删除）

#### 3. 实时时钟
- 每秒更新一次，所有城市时间同步刷新
- 时间轴右侧显示**实时**状态（绿色点 = 实时运行中）
- 手动拖动后按钮变为 "↺ 回到实时"，点击恢复实时模式

#### 4. 可拖动时间轴与城市矩阵
- 顶部 24 小时时间轴可拖动，拖动后根据本地城市时间反推 UTC → **全部城市同步联动**
- 城市矩阵按小时列展示每个城市的工作状态
- 当前小时列高亮并显示各城市本地时间
- 图例：绿色=工作时间，黄色=边缘时间，灰色=休息时间

#### 5. 工作状态判断
| 状态 | 时间范围 | 颜色 |
|------|---------|------|
| 工作中 | 09:00–17:00 | 绿色 |
| 边缘时段 | 08:00–09:00 / 17:00–19:00 | 琥珀色 |
| 休息 | 其余时段 | 灰色 |

#### 6. 城市信息展示（每行）
- 国旗 emoji + 城市名 + 国家名
- 当前日期、星期和本地时间
- 与本地城市的跨天状态
- 非本地城市可移除

#### 7. 添加城市
- 点击底部虚线按钮弹出搜索面板
- 支持按城市名 / 国家名搜索（中文）
- 已添加的城市不在列表中重复显示

#### 8. 汇率换算
- 数据源：`https://api.frankfurter.dev`
- 基准：人民币 CNY，页面显示各外币兑人民币汇率
- 默认关注货币：USD、EUR、GBP
- 支持输入外币金额并快速换算成人民币
- 支持添加 / 移除关注货币，关注列表保存在 `localStorage` 的 `clock-board-currencies`
- 支持手动刷新汇率

#### 9. 汇率走势
- 右侧展示选中货币兑人民币走势
- 支持 7 天 / 1 个月区间切换
- 图表为轻量 SVG 折线图
- 页面提示“仅供参考，以中行为准”

### 数据与技术

- 时区计算：`Intl.DateTimeFormat` + `formatToParts`，全部基于 UTC，正确处理 DST
- 夏令时检测：对比 1 月 / 7 月 UTC 偏移量
- 跨天差值：以上海（本地城市）当日 0 时为基准计算
- 状态管理：`useState` + `useRef` + `useMemo`，`useCallback` 做性能保护
- 汇率请求：客户端 fetch Frankfurter API，包含加载、失败和重试状态

## 二、全球节假日（Global Holidays）

**文件**：
- `src/features/holidays/app/HolidaysPage.tsx`
- `src/features/holidays/data/holidays2026.ts`

### 功能概览

展示 2026 年全球节假日，按中国假日 / 国际假日 / 宗教节日三类组织，支持地区和教派二级筛选，按月分组列出，倒计时高亮即将到来的假日。假日行支持展开查看“假期背景”“假期表现与商务影响”“禁忌与注意事项”。

### 核心功能

#### 1. 一级分类 Tab
| Tab | 内容 |
|-----|------|
| 全部 | 显示所有假日，可叠加地区筛选 |
| 中国假日 | 仅显示 `category: 'china'` |
| 国际假日 | 仅显示 `category: 'international'`，可按地区筛选 |
| 宗教节日 | 仅显示 `category: 'religious'`，可按教派筛选 |

移动端：Tab 全宽横排，各项等分（`flex-1`）

#### 2. 二级筛选芯片

**国际假日 / 全部模式**（按地区）：
全部 / 美国 / 英国 / 欧洲 / 日本 / 韩国 / 印度 / 东南亚 / 中东土耳其 / 美洲 / 其他

**宗教节日模式**（按教派）：
全部 / 伊斯兰教 / 犹太教 / 佛教 / 印度教

移动端：单行横向滚动（`flex-nowrap overflow-x-auto`），延伸至屏幕边缘

> 地区由 `holiday.id` 前缀自动推断（`us-` → 美国，`jp-` → 日本……），无需在数据中额外存储字段。

#### 3. 全年展示（按月分组）
- 显示 2026 年全部假日，不做日期截断
- 按月份分组，每组显示月份标题 + 该月假日数量
- 月份标题格式：`一月  2026年1月  ● X 个假日`
- 页面首次进入时会即时定位到当前月份；如果当前筛选下没有当前月份，则定位到当前月份之后的第一个月份
- 定位使用 `behavior: 'auto'`，不做平滑滚动动画；展开 / 收起详情不会触发页面滚动

#### 4. 假日行信息
每行从左到右：
- **日期列**（`MM/DD`，多日显示起止 + 共 N 天）
- **分类彩点**（红=中国 / 绿=国际 / 琥珀=宗教）
- **名称**（emoji + 中文名 + 英文名）
- **倒计时徽章** + **分类徽章** + 展开箭头

#### 5. 展开详情
点击假日行右侧箭头展开详情区，内容来自 `getHolidayDetail(holiday)`：
- **假期背景**：节日来源、文化或国家纪念背景
- **假期表现与商务影响**：办公室、银行、物流、审批、回复节奏等业务影响
- **禁忌与注意事项**：问候语、催单、会议、付款、清关等沟通建议

数据优先匹配重点节日的专属文案；未命中的节日按中国 / 国际 / 宗教分类生成通用说明。

#### 6. 倒计时高亮
| 状态 | 徽章样式 |
|------|---------|
| 今天 | 橙色实心 |
| 进行中（多日假日） | 绿色实心 |
| 7 天内 | 琥珀色 |
| 8–30 天 | 蓝色 |
| 30 天以上 | 灰色 |
| 已过去 | 不显示倒计时徽章，行内容保持正常可读 |

### 数据结构

```typescript
interface Holiday {
  id: string;             // 前缀标识地区，如 us-thanksgiving
  dateStart: string;      // YYYY-MM-DD
  dateEnd?: string;       // 多日假日结束日期
  days?: number;          // 总天数
  nameCN: string;
  nameEN: string;
  category: 'china' | 'international' | 'religious';
  emoji?: string;         // 国旗或宗教符号
  religion?: 'islam' | 'jewish' | 'buddhism' | 'hinduism';
}

interface HolidayDetail {
  background: string;
  businessImpact: string;
  notes: string;
}
```

2026 年共收录约 **186 个假日**，覆盖中国、美国、英国、欧洲主要国家、日本、韩国、印度、东南亚、中东、美洲等地区，以及伊斯兰教、犹太教、佛教、印度教四大宗教节日。

## 三、通用设计规范

- **页面宽度**：全宽 `w-full`，不设最大宽度限制，内边距 `px-3 sm:px-6`
- **深色模式**：所有组件均实现 `dark:` 变体
- **认证保护**：未登录自动跳转 `/`，`next-auth` session 管理
- **框架**：Next.js App Router，`'use client'` 组件，TypeScript strict 模式

## 一、世界时钟（World Clock）

**文件**：`src/features/clock/app/ClockPage.tsx`

### 功能概览

实时展示全球多城市的当地时间，支持时间轴拖动查看任意时刻各地时间，并判断各城市工作状态。

### 核心功能

#### 1. 默认城市与本地城市
- 本地城市固定为 **上海**（`HOME_CITY_ID = 'shanghai'`）
- 默认显示 8 座城市：上海、纽约、洛杉矶、伦敦、柏林、悉尼、迪拜、新德里
- 可在 34 座全球城市中自由添加 / 删除（本地城市不可删除）

#### 2. 实时时钟
- 每秒更新一次，所有城市时间同步刷新
- 页头右侧显示**实时**按钮（蓝色脉冲点 = 实时运行中）
- 手动拖动后按钮变为 "↺ 回到实时"，点击恢复实时模式

#### 3. 可拖动时间条（每城市行内置）
- 每条城市行底部内嵌一条 **24 小时渐变色带**（灰=休息 / 琥珀=边缘时段 / 蓝=工作时间）
- 色带上的拖柄显示为该城市的**国旗 emoji**，上方跟随显示当前时间气泡
- 拖动任意城市的时间条 → 根据该城市本地时间反推 UTC → **全部城市同步联动**
- 刻度标签（0 / 6 / 12 / 18 / 24）通过绝对定位完整显示，不截断

#### 4. 工作状态判断
| 状态 | 时间范围 | 颜色 |
|------|---------|------|
| 工作中 | 09:00–17:00 | 蓝色 |
| 边缘时段 | 08:00–09:00 / 17:00–19:00 | 琥珀色 |
| 休息 | 其余时段 | 灰色 |

#### 5. 城市信息展示（每行）
- 国旗 emoji + 城市名 + 国家名
- 日期、星期
- 跨天徽章（+1天 / -1天，绿色/橙色）
- 夏令时徽章（`夏令`，紫色）
- 工作状态徽章
- 当前时间（等宽字体，`HH:MM`）

#### 6. 添加城市
- 点击底部虚线按钮弹出搜索面板
- 支持按城市名 / 国家名搜索（中文）
- 已添加的城市不在列表中重复显示

### 数据与技术

- 时区计算：`Intl.DateTimeFormat` + `formatToParts`，全部基于 UTC，正确处理 DST
- 夏令时检测：对比 1 月 / 7 月 UTC 偏移量
- 跨天差值：以上海（本地城市）当日 0 时为基准计算
- 状态管理：`useState` + `useRef` + `useMemo`，`useCallback` 做性能保护

## 二、全球节假日（Global Holidays）

**文件**：
- `src/features/holidays/app/HolidaysPage.tsx`
- `src/features/holidays/data/holidays2026.ts`

### 功能概览

展示 2026 年全球节假日，按中国假日 / 国际假日 / 宗教节日三类组织，支持地区和教派二级筛选，按月分组列出，倒计时高亮即将到来的假日。

### 核心功能

#### 1. 一级分类 Tab
| Tab | 内容 |
|-----|------|
| 全部 | 显示所有假日，可叠加地区筛选 |
| 中国假日 | 仅显示 `category: 'china'` |
| 国际假日 | 仅显示 `category: 'international'`，可按地区筛选 |
| 宗教节日 | 仅显示 `category: 'religious'`，可按教派筛选 |

移动端：Tab 全宽横排，各项等分（`flex-1`）

#### 2. 二级筛选芯片

**国际假日 / 全部模式**（按地区）：
全部 / 美国 / 英国 / 欧洲 / 日本 / 韩国 / 印度 / 东南亚 / 中东土耳其 / 美洲 / 其他

**宗教节日模式**（按教派）：
全部 / 伊斯兰教 / 犹太教 / 佛教 / 印度教

移动端：单行横向滚动（`flex-nowrap overflow-x-auto`），延伸至屏幕边缘

> 地区由 `holiday.id` 前缀自动推断（`us-` → 美国，`jp-` → 日本……），无需在数据中额外存储字段。

#### 3. 全年展示（按月分组）
- 显示 2026 年全部假日，不做日期截断
- 按月份分组，每组显示月份标题 + 该月假日数量
- 月份标题格式：`一月  2026年1月  ● X 个假日`

#### 4. 假日行信息
每行从左到右：
- **日期列**（`MM/DD`，多日显示起止 + 共 N 天）
- **分类彩点**（红=中国 / 绿=国际 / 琥珀=宗教）
- **名称**（emoji + 中文名 + 英文名）
- **倒计时徽章** + **分类徽章** + 展开箭头

#### 5. 倒计时高亮
| 状态 | 徽章样式 |
|------|---------|
| 今天 | 橙色实心 |
| 进行中（多日假日） | 绿色实心 |
| 7 天内 | 琥珀色 |
| 8–30 天 | 蓝色 |
| 30 天以上 | 灰色 |
| 已过去 | 整行 `opacity-35` 淡出 |

### 数据结构

```typescript
interface Holiday {
  id: string;             // 前缀标识地区，如 us-thanksgiving
  dateStart: string;      // YYYY-MM-DD
  dateEnd?: string;       // 多日假日结束日期
  days?: number;          // 总天数
  nameCN: string;
  nameEN: string;
  category: 'china' | 'international' | 'religious';
  emoji?: string;         // 国旗或宗教符号
  religion?: 'islam' | 'jewish' | 'buddhism' | 'hinduism';
}
```

2026 年共收录约 **186 个假日**，覆盖中国、美国、英国、欧洲主要国家、日本、韩国、印度、东南亚、中东、美洲等地区，以及伊斯兰教、犹太教、佛教、印度教四大宗教节日。

## 三、通用设计规范

- **页面宽度**：全宽 `w-full`，不设最大宽度限制，内边距 `px-3 sm:px-6`
- **深色模式**：所有组件均实现 `dark:` 变体
- **认证保护**：未登录自动跳转 `/`，`next-auth` session 管理
- **框架**：Next.js App Router，`'use client'` 组件，TypeScript strict 模式

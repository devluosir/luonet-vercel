# 客户管理用户指南

最后更新：2026-07-02

## 入口

左侧菜单进入「客户管理」。

页面包含三个资料库：

- 客户
- 供应商
- 收货人

## 客户资料

客户资料由公司信息和联络人列表组成。

公司信息包括：

- 公司全称
- 简称
- 编号
- 地址
- 电话
- 邮箱
- 分类
- 分类备注

联络人信息包括：

- 姓名
- 简称
- 电话
- 邮箱
- 是否主联络人

## 客户分类

客户可标记为：

- A类
- B类
- C类
- New
- 黑名单

分类只适用于客户，不适用于供应商和收货人。分类备注用于记录评定理由。

## 列表和卡片

客户管理页支持列表视图和卡片视图。

- 点击行或卡片进入详情。
- 编辑、删除在菜单中操作。
- 搜索框可按名称、简称、编号、联络人等信息查找。
- 客户 tab 支持按分类筛选。

## 客户详情

客户详情页显示：

- 公司信息
- 全部联络人
- 客户分类和备注
- 业务统计
- 活动列表
- 跟进记录

活动列表会显示该客户所有联络人的询价记录。已成单询价如果在编辑询价时标记为「辙销C」「悬挂P」或「善后S」，这里会显示对应状态；列表右侧会按实际存在的状态显示筛选按钮。若填写了情况备注，备注会跟在活动描述后方，并按辙销红色、悬挂绿色、善后蓝色显示。

## 与询报价联动

新增询价时需要选择客户和联络人。编辑已关联询价时，联络人显示以客户资料为准。

批量关联客户可在询报价登记页使用，用于处理历史未关联记录。

## 注意事项

- 不要把邮件正文、称呼、整段地址粘贴成客户名称。
- 装箱单的 Consignee 自由文本不会再自动保存为收货人资料。
- 如果客户有简称而联络人没有简称，询价选择器只显示客户简称。

### 🔄 功能流程

```
用户点击转换按钮
    ↓
获取订单确认记录
    ↓
验证记录存在性
    ↓
检测合并单元格
    ↓
显示确认对话框（如有合并）
    ↓
用户确认
    ↓
执行数据转换
    ↓
保存装箱单历史
    ↓
显示成功提示
    ↓
跳转到装箱单编辑页面
```

### 🎯 字段映射

| 源字段 (订单确认) | 目标字段 (装箱单) |
|------------------|------------------|
| contractNo | orderNo |
| to | consignee.name |
| date | date |
| currency | currency |
| partName | marks ⭐ |
| description | description ⭐ |
| quantity | quantity |
| unit | unit |
| unitPrice | unitPrice |
| amount | totalPrice |

⭐ = 保留合并单元格信息

### 🛡️ 错误处理

1. **记录不存在**
   - 提示: "未找到订单确认记录"
   - 操作: 终止转换

2. **保存失败**
   - 提示: "转换失败，请重试"
   - 操作: 终止转换，不创建记录

3. **异常捕获**
   - 提示: "转换失败: [错误信息]"
   - 操作: 记录日志，显示详细错误

4. **用户取消**
   - 操作: 静默取消，不显示提示

2. 暂不支持转换前预览

### 解决方案

对于已知限制，用户可以：
1. 逐个转换记录
2. 转换后立即检查数据
3. 使用默认的字段映射
4. 删除错误的记录并重新转换

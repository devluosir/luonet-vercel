# 订单确认转装箱单功能文档

## 快速开始

### 基本使用
1. 进入历史记录页面 `/history`
2. 切换到"订单确认"标签页
3. 点击记录右侧的"转换为装箱单"按钮
4. 如有合并单元格，确认转换
5. 自动跳转到装箱单编辑页面完善信息

### 注意事项
- 转换后需要补充海关编码、重量等信息
- 原订单确认记录不会被修改
- 支持重复转换同一记录

## 功能详情

### 字段映射
| 订单确认字段 | 装箱单字段 | 说明 |
|-------------|-----------|------|
| `partName` | `marks` | 商品名称转换为唛头 |
| `description` | `description` | 描述信息保持不变 |
| `quantity` | `quantity` | 数量 |
| `unit` | `unit` | 单位 |
| `unitPrice` | `unitPrice` | 单价 |
| `amount` | `totalPrice` | 总价 |
| `contractNo` | `orderNo` | 合同号作为订单号 |
| `to` | `consignee.name` | 客户名称作为收货人 |
| `currency` | `currency` | 币种 |
| `date` | `date` | 日期 |

### 数据处理
- 保留合并单元格信息
- 保留高亮状态
- 保留列显示设置
- 设置装箱单特有字段的默认值

## 常见问题

### Q: 如何处理合并单元格？
A: 系统会自动保留合并的名称和描述列信息，转换为装箱单对应字段。

### Q: 是否会影响原始记录？
A: 不会。转换会创建新的装箱单记录，原订单确认记录保持不变。

### Q: 如何修改转换后的数据？
A: 转换完成后会自动跳转到装箱单编辑页面，可以直接修改。

### Q: 支持批量转换吗？
A: 目前不支持，计划在v1.1.0版本添加此功能。

# 订单确认转装箱单功能测试指南

## 测试目的

验证订单确认记录能够正确转换为装箱单记录，并保留所有合并的名称和描述列信息。

## 测试前准备

### 1. 准备测试数据

在报价单页面创建一个订单确认书，确保包含：
- 至少3-5个商品项
- 包含 partName（商品名称）
- 包含 description（描述信息）
- 设置合同号（contractNo）
- 设置客户名称（to）
- 设置币种和日期

### 2. 保存订单确认

点击"保存"按钮，确保订单确认已保存到历史记录。

## 测试步骤

### 测试用例1：基本转换功能

1. **导航到历史记录页面**
   - 访问 `/history` 页面
   - 切换到"订单确认"标签页

2. **查找测试记录**
   - 在列表中找到刚创建的订单确认记录
   - 确认记录显示正确

3. **执行转换**
   - 点击记录右侧的"转换为装箱单"按钮（Package图标）
   - 观察是否显示确认对话框（如果有合并单元格）

4. **验证转换结果**
   - 检查是否显示"订单确认已成功转换为装箱单！"提示
   - 确认自动跳转到装箱单编辑页面
   - 验证URL格式为 `/packing/edit/{id}`

### 测试用例2：数据映射验证

在装箱单编辑页面，验证以下字段映射是否正确：

| 原字段（订单确认） | 目标字段（装箱单） | 验证方法 |
|------------------|------------------|---------|
| contractNo | orderNo | 检查"Order No"输入框 |
| to | consignee.name | 检查"Consignee"输入框 |
| date | date | 检查日期选择器 |
| currency | currency | 检查币种选择器 |
| items[].partName | items[].marks | 检查表格中的"Marks"列 |
| items[].description | items[].description | 检查表格中的"Description"列 |
| items[].quantity | items[].quantity | 检查表格中的"Quantity"列 |
| items[].unit | items[].unit | 检查表格中的"Unit"列 |
| items[].unitPrice | items[].unitPrice | 检查表格中的"Unit Price"列 |
| items[].amount | items[].totalPrice | 检查表格中的"Total Price"列 |

### 测试用例3：合并单元格信息保留

如果订单确认包含合并的单元格：

1. **创建包含合并单元格的订单确认**
   - 使用粘贴功能导入包含合并单元格的数据
   - 确保有合并的描述列或名称列

2. **转换时验证提示**
   - 点击转换按钮
   - 确认显示合并单元格信息提示
   - 提示内容应包含：
     - 合并的描述列数量
     - 字段映射说明（名称列→唛头，描述列→描述）
     - 确认/取消按钮

3. **转换后验证**
   - 确认合并的名称列内容出现在"Marks"列中
   - 确认合并的描述列内容出现在"Description"列中
   - 验证合并信息的起始行和结束行位置正确

### 测试用例4：高亮信息保留

1. **创建包含高亮的订单确认**
   - 双击某些单元格添加高亮
   - 保存订单确认

2. **转换并验证**
   - 执行转换
   - 在装箱单编辑页面检查高亮是否保留
   - 验证高亮的字段映射是否正确（partName→marks, description→description）

### 测试用例5：列显示设置保留

1. **自定义列显示**
   - 在订单确认页面，隐藏某些列（如果支持）
   - 保存订单确认

2. **转换并验证**
   - 执行转换
   - 在装箱单页面检查列显示设置是否保留
   - 验证 `savedVisibleCols` 是否正确传递

### 测试用例6：默认值设置

在转换后的装箱单中，验证以下默认值：

- `invoiceNo`: 应为空
- `hsCode`: 每个商品项应为空
- `netWeight`: 每个商品项应为0
- `grossWeight`: 每个商品项应为0
- `packageQty`: 每个商品项应为0
- `dimensions`: 每个商品项应为空
- `documentType`: 应为 'both'
- `showPrice`: 应为 true
- `showWeightAndPackage`: 应为 true
- `showHsCode`: 应为 false
- `showDimensions`: 应为 false
- `isInGroupMode`: 应为 false

### 测试用例7：历史记录独立性

1. **转换后检查订单确认**
   - 返回历史记录页面
   - 切换到"订单确认"标签页
   - 确认原订单确认记录仍然存在，未被修改或删除

2. **检查装箱单历史**
   - 切换到"装箱单"标签页
   - 确认新创建的装箱单记录存在
   - 验证两个记录的ID不同

3. **修改测试**
   - 编辑装箱单，修改某些字段
   - 保存装箱单
   - 返回查看订单确认，确认未受影响

### 测试用例8：错误处理

1. **无效记录ID**
   - 尝试使用不存在的ID调用转换功能
   - 验证显示错误提示："未找到订单确认记录"

2. **非订单确认类型**
   - 尝试转换类型为 'quotation' 的记录（如果可能）
   - 验证转换失败并显示适当提示

3. **取消转换**
   - 点击转换按钮
   - 在确认对话框中点击"取消"
   - 验证未创建新的装箱单记录
